# meet

A simple group video call app built with React, Vite, and [ZEGOCLOUD](https://www.zegocloud.com/) [Prebuilt UIKit](https://www.zegocloud.com/docs/uikit/video-conference-kit/overview).

## Setup

1. Create an app in the [ZEGOCLOUD console](https://console.zegocloud.com/) and copy your App ID and Server Secret.
2. Add a `.env` file:

```
ZEGOCLOUD_ID=your_app_id
ZEGOCLOUD_SERVER_SECRET=your_server_secret
```

3. Install and run:

```
npm install
npm run dev
```
